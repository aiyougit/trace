# 迹 · Trace v0.3.0

首个开源预览版本：原生 macOS 数字足迹工具，支持 macOS 13+，兼容 Apple Silicon 与 Intel。

## 功能

- 220 × 44 点桌面悬浮条：当天鼠标距离与键盘输入次数，拖动、右键操作、轻微透明磨砂。
- 统计面板：今天 / 累计、小时活动、键盘热力图、按键排行。
- 可选中英文词语画像，默认关闭；应用排除、暂停、JSON 导出和数据清理。
- 奶油黄木色「浅色 · 淡木」与「深色 · 夜色」，悬浮条同步适配。
- 主面板不置顶；最小化、关闭或切换应用自动收起为悬浮条；支持 Dock 和菜单栏。
- 无第三方运行依赖，统计只保存在本机，不发起网络请求。

## 下载与安装

- **推荐：`Trace-0.3.0-universal.pkg`**，退出旧版后安装到 `/Applications/Trace.app`。
- **免安装器：`Trace-0.3.0-universal.app.zip`**，解压后将 Trace.app 拖到「应用程序」。
- `SHA256SUMS.txt`：使用 `shasum -a 256 -c SHA256SUMS.txt` 校验同目录的两个下载文件。
- GitHub 自动附带的 Source code 为源码，不是可直接运行的安装包。

## 授权与已知限制

基础统计需要「输入监控」，词语画像另外需要「辅助功能」。请授权固定路径 `/Applications/Trace.app`，然后重启应用。

**当前应用为 ad-hoc 临时签名，PKG 未进行 Developer ID 签名和 Apple 公证。** macOS 可能阻止打开，请核对来源与校验和，并按系统提供的官方入口决定是否允许，也可自行编译。无需关闭 Gatekeeper 或系统完整性保护。

重新编译后，macOS 可能不再认可旧权限开关；移除旧条目、重新添加应用并开启后重启即可，不需要删除统计。

鼠标距离为屏幕光标路径估算；词语画像依赖受支持应用的辅助功能文本，无法保证完整、精确归因。数据仅按天汇总保存，不记录原始段落或按键时间线。
