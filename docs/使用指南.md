# 迹 · Trace 使用指南

一个原生 macOS 数字足迹工具。可拖动的 220 × 44 点的桌面悬浮条仅显示当天鼠标移动距离与键盘输入次数，展开后查看按键热力、小时活跃分布和中英文词语画像。使用 SwiftUI、AppKit、CoreGraphics、Accessibility 与系统 NaturalLanguage，无第三方依赖。

## 开始使用

1. 将 `dist/Trace.app` 拖到「应用程序」后双击运行。当前交付包为 Apple Silicon / Intel 通用版本，最低 macOS 13。
2. 进入「设置与隐私」，点击「输入监控 → 开启权限」。在系统设置的「隐私与安全性 → 输入监控」中开启 Trace。如果列表中没有 Trace，用 `+` 选择应用。
3. 权限更改后，如果没有开始统计，点击应用中的「退出并重新打开」。若系统开关已开但仍未生效，请按下面「授权修复」处理。
4. 点击左下角「切换悬浮窗」。悬浮条可以拖动，右键菜单可展开面板、暂停 / 恢复、隐藏到菜单栏。窗口会浮在普通窗口上，并可在桌面空间之间显示；独占全屏应用、系统安全界面可能不允许覆盖。
5. 想统计词语时，在「设置与隐私」打开「词语画像」，并在系统「辅助功能」中开启 Trace。不开启此项也可以使用鼠标和键盘次数统计。

统计面板是普通窗口，不置顶；只有悬浮条置顶。点击黄色最小化按钮、关闭面板或切换到其他应用时，会自动切换到悬浮条，并保留面板所在页面。有文件选择器或模态对话框打开时不自动折叠。Dock 显示应用图标，点击 Dock 图标可再次展开统计面板。

菜单栏可切换面板 / 悬浮条、暂停统计、重新打开和退出。退出会停止统计，程序记住上次使用的悬浮窗模式。

在「设置与隐私 → 外观主题」可选择「浅色 · 淡木」或「深色 · 夜色」。浅色使用清淡的黄木与奶油米色，面板、键盘热力图、词语画像和悬浮条同步切换，重启后保留选择。悬浮条使用轻微透明的原生磨砂背景，文字保持不透明；系统开启「降低透明度」时自动使用实色背景。主题保存在应用偏好中，与统计数据分开。

## 授权修复

无需卸载或重新下载。当前为临时签名开发版，每次重新编译都会改变签名的代码哈希。系统权限列表里的旧开关可能仍显示开启，但不再适用于更新后的程序。

1. 只使用 `/Applications/Trace.app`，不要同时运行项目 `dist` 目录的另一份。
2. 在系统设置「隐私与安全性 → 输入监控」中移除旧 Trace，再点击加号，选择 `/Applications/Trace.app` 并开启。文件选择器中可按 `⌘⇧G` 输入完整路径。
3. 如使用词语画像，在「辅助功能」列表对 Trace 做同样处理。
4. 在 Trace 设置页或菜单栏点击「退出并重新打开」，再检查「监听已连接」。本地统计不会删除。

应用显示的是系统 API 返回给当前进程的状态，无法读取系统设置开关来猜测授权。若系统报告已授权但事件监听未启动，设置页会单独提示并提供重启入口。

## 功能与统计口径

- **鼠标距离**：累计光标在屏幕上的路径，使用显示器报告的物理尺寸将系统坐标换算为米，超过 1,000 米自动显示公里；包含拖拽。它是屏幕轨迹的估算值，不是桌面上实体鼠标行走的距离。显示器没有报告尺寸时按 110 PPI 估算；跨屏跳变不累计，高速事件合并也可能低估轨迹。
- **按键频率**：按 macOS 物理键码统计独立按下次数，包括修饰键；忽略长按产生的自动重复。ANSI 热力图展示主要键位，所有记录过的键均出现在排行中。键帽不随第三方键盘布局变化，媒体键和某些硬件功能键未纳入。
- **词语画像**：通过辅助功能读取受支持文本输入框的变化，用系统分词器进行中英文分词，过滤纯数字、单字和部分常见虚词，显示词频及已识别字符数。只给开启之后在已观察输入框内新增的文字归因，不把输入框里原有的整篇文章作为输入记录。当前编辑中的输入法替换和删除会修正这一次输入框会话的贡献。
- **今天 / 累计**：按本地日历日归档，默认展示当天；累计显示所有日期汇总，活跃时刻为对应范围内的每小时按键汇总。
- **本地管理**：按天保存、JSON 导出、清空词语画像、清空所有统计、按应用排除、全局暂停。默认排除常见密码管理器和终端的按键及文字统计；鼠标距离仍累计。

## 词语画像的边界

词语画像默认关闭。开启后，读取的输入框基线和当前编辑草稿只短暂保留在内存中，用来区分新增文字及修正编辑；磁盘仅保存按天汇总的词语及次数，不保存原始段落、按键顺序、剪贴板或输入时间线。关闭、暂停、切换输入框会释放这份内存草稿。

系统标记的密码输入框、受保护内容和安全输入模式会被跳过。自定义输入框不一定正确暴露安全标记，处理敏感内容可暂停统计或排除应用。词频本身也可能包含私人词语，本地文件和导出文件请自行保管。

并非所有应用支持 Accessibility 文本值，例如一些编辑器、游戏、网页编辑器或自绘输入框。程序不会注入应用、截屏识字或绕过安全输入；此类场景会显示未支持 / 已跳过。当前采用键入后约 650 ms 稳定文本采样，输入法候选、自动补全、语音输入、菜单粘贴、快速切换输入框或在旧文本中间插入可能影响分词或归因。键盘快捷键 `⌘V` 会跳过一次粘贴采样，不能视为完整的输入来源鉴别。长于 30,000 个 UTF-16 单元的输入框不参与画像。每日词表限制约 5,000 项，超限会保留高频词。当前版本提供词频轮廓，不提供逐字回放或完整文章记录。

## 数据位置

`~/Library/Application Support/Trace/statistics.json`

每 10 秒原子写入，正常退出时立即保存，文件权限为当前用户读写。应用不发起网络请求，不安装常驻服务。读取损坏文件失败时会保留原文件，界面提供「备份原文件并重试保存」。突然断电可能丢失最近 10 秒内的统计。

## 构建与检查

需要 macOS 13+ 和 Apple Command Line Tools / Xcode，Swift 5.9+。不需要安装 Node、Electron 或额外包。

```sh
./scripts/build.sh              # 当前机器架构的 .app
./scripts/build.sh --universal  # Apple Silicon + Intel 通用 .app
./scripts/package.sh            # 将现有通用 .app 封装为原生 .pkg，不重新编译
./scripts/test.sh               # 直接编译真实核心代码，运行 10 项检查
./scripts/preview.sh            # 用独立临时数据生成界面预览 PNG
open dist/Trace.app
```

安装包输出为 `dist/Trace-0.3.0-universal.pkg`。双击后按系统安装器提示安装到 `/Applications/Trace.app`，安装前先退出正在运行的 Trace。安装包包含欢迎页与使用说明，不包含启动服务或修改隐私授权的安装脚本，也不会删除用户统计。安装位置固定，避免系统误将更新安装到项目里的另一份应用。打包只复制现有已签名程序，保持二进制及其签名不变。

当前 `.pkg` 未经 Developer ID Installer 签名和公证。若已安装对应证书，可通过 `TRACE_INSTALLER_IDENTITY` 指定安装包签名身份；应用签名与安装包签名是两个独立步骤。也可用 `./scripts/package.sh /Applications/Trace.app` 封装固定安装位置的现有通用应用。

当前环境只有 Command Line Tools，没有 XCTest 运行库，所以核心检查使用独立 Swift 可执行检查程序，涵盖物理距离换算、Retina 坐标、文本来源归因、IME 替换、Unicode 编辑、分词、跨日汇总、暂停、本地持久化和损坏文件保护。预览数据仅存在独立临时目录，不会污染真实数据；`dist/previews/*-sample.png` 内的数字为示例。

应用包采用本地 ad-hoc 签名，适合本机开发使用。若面向外部用户正式分发，还需要 Apple Developer ID 签名、公证和安装分发流程。临时签名的指定要求绑定当前二进制哈希，重新编译后可能需要移除旧授权并重新添加；先放到固定位置再授权。

构建脚本支持通过 `TRACE_CODESIGN_IDENTITY` 指定已安装的签名身份。使用同一受支持证书签署后续更新可保持签名身份。当前机器没有有效的代码签名证书，本次仍使用临时签名。

## 目录

- `Sources/Trace/TraceApp.swift`：菜单栏、窗口、悬浮与展开切换。
- `Sources/Trace/Core/`：事件监听、物理距离、输入草稿归因、分词与本地存储。
- `Sources/Trace/UI/`：概览、键盘热力图、词语画像、设置及悬浮窗。
- `Tests/`：核心检查和离屏界面预览工具。
- `Resources/Info.plist`：应用信息。
- `scripts/`：打包、图标生成、检查与预览。
