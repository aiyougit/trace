# 迹 · Trace for Windows 0.1.2

## 最小化 / 关闭改为隐藏到托盘

- 点击统计面板右上角的「—」或「×」（包括 Alt+F4）：面板和悬浮条一起隐藏到右下角系统托盘，任务栏按钮消失，**后台统计继续**。
- **左键双击托盘图标**恢复统计面板；右键可展开面板、显示悬浮条、暂停 / 继续统计。
- 应用内的 **「退出 Trace」统一放在托盘右键菜单**，悬浮条菜单不再提供退出选项。
- 切换其他应用时仍按原有逻辑收起为悬浮条；手动切换悬浮模式也保留。
- 防止已经排队的失焦回调在隐藏到托盘后重新弹出悬浮条，恢复后重新显示正常任务栏入口。

Windows 可能将图标放在右下角「显示隐藏的图标」（向上箭头）区域；找不到时先展开该区域。

## 下载与更新

- **Intel / AMD 电脑、Windows Server 2019**：`Trace-0.1.2-windows-x64-setup.exe`。
- **ARM64 电脑**：`Trace-0.1.2-windows-arm64-setup.exe`。
- 也提供对应架构的便携 ZIP 和 SHA-256 清单。

更新前可先从旧版托盘右键菜单退出 Trace，再运行新安装包覆盖安装。安装器自带 .NET 运行时，更新不主动删除本地统计。

保留 Windows 10 1809（17763）及以上 / Windows 11 / Windows Server 2019 及以上桌面体验版的兼容目标。Server 2019 使用 x64；不支持 Server Core / Nano 或跨用户会话统计。程序及安装器未进行商业代码签名。

## 验证范围

云端检查覆盖系统版本基线、17 项核心逻辑、两套主题渲染、原生接口、重复最小化 / 关闭到托盘、窗口恢复、悬浮条隐藏、退出菜单位置以及 x64 安装 / 卸载。检查使用独立临时数据，不读取真实用户统计。Server 2019 和 ARM64 的实际运行仍需对应设备验证。
